# PowerPoint 版

`../实验室安全答辩.pptx` 由 `build.js` 生成，内容与 `../web/` 网页版一一对应（8 章 24 页，每页带备注提词）。

- 重新生成：在仓库根目录运行 `node slides/pptx/build.js`（需要 pptxgenjs）
- 第 23 页「实物运行」是三张灰色占位图：在 PowerPoint 里右键 → 更改图片，位置和尺寸会保留
- 曲线数据：`curves.json`（取自 `labguard/models/model_card.json`）
- 字体：标题「思源宋体」，正文「更纱黑体 SC」，代码 Consolas。放映的电脑没装这两套字体时 PowerPoint 会换成默认字体，请先安装（均为 SIL OFL 开源字体）
- 第 10、15、16 页的实机截图取自 `../web/img/`（原图在 `docs/上手指南图片/`）
